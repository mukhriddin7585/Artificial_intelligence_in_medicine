# Kirish ma’lumotlari lug‘ati
api_training.csv: sun’iy age, bmi, systolic_bp belgilaridan hosil qilingan o‘quv target. Natija klinik xavf ehtimoli emas.

## api_training.csv
Qatorlar soni: 500.
| Ustun | Turi | Ma’nosi |
|---|---|---|
| age | int64 | Yosh, yil |
| bmi | float64 | Tana massasi indeksi, kg/m² |
| systolic_bp | float64 | Sistolik bosim, mmHg |
| target | int64 | Sun’iy hosil qilingan target, 0/1; klinik tashxis emas |
