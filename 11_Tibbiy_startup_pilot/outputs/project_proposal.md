# Tibbiy tasvirlar navbatini ko‘rib chiqish prototipi

Foydalanuvchi: mutaxassis. Chiqish: ko‘rib chiqish navbati.
Jarayon: tasvir → sifat nazorati → model → mutaxassis tasdig‘i.
Pilot: avval kuzatuv rejimi; qarorlar mutaxassisda qoladi.
KPI: vaqt, xatolar, override ulushi va tizim mavjudligi.
To‘xtatish mezoni oldindan klinik hamkor bilan belgilanadi.
Natijalar sun’iy; foyda yoki klinik samaradorlik isbotlanmagan.
