# Kirish ma’lumotlari lug‘ati
heart_disease.csv: sun’iy yurak xavfi ma’lumotlari. Target simulyatsiya formulasi bilan yaratilgan, klinik tashxis emas.

## heart_disease.csv
Qatorlar soni: 700.
| Ustun | Turi | Ma’nosi |
|---|---|---|
| patient_id | int64 | Sun’iy bemor identifikatori yoki ochiq dataset qatori |
| age | int64 | Yosh, yil |
| bmi | float64 | Tana massasi indeksi, kg/m² |
| systolic_bp | float64 | Sistolik bosim, mmHg |
| sex_group | object | Sun’iy A/B guruh; haqiqiy demografik ma’lumot emas |
| target | int64 | Sun’iy hosil qilingan target, 0/1; klinik tashxis emas |
